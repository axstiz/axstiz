## > Опыт работы

##### Разработка on-premise AI-анализатора потоковых логов кибербезопасности
[WaveScan](https://github.com/Mitoshi-Team/AI-CyberLogAgent) — проектный практикум УрФУ (реальный заказчик)

Роль: `AI-инженер`, `AI-архитектор`, `бэкенд-разработчик`

Спроектировал и реализовал AI-ядро пайплайна потокового анализа логов. Система в реальном времени читает логи через Vector → Kafka, обрабатывает в LangGraph DAG (8 узлов, параллельные AI + детерминированные ветки), сохраняет результаты в Postgres и уведомляет веб-интерфейс.

**Ключевые результаты и архитектурные решения:**

- Спроектировал полную схему потоков: Vector (file source + Lua chunking 250 строк, overlap 20, flush 180s) → Kafka (topic: processed-logs-batches) → Kafka consumer (aiokafka, retry 3×, exp backoff, DLQ) → LangGraph DAG → Postgres
- Разработал 8-узловой LangGraph StateGraph с параллельными ветками: AI-анализ (Agent 1 → RAG → Agent 3) и детерминированный (YARA + Sigma). Впервые в открытом доступе представил архитектуру скрещивания LLM и сигнатурных движков в одном графе
- Реализовал гибридный RAG (ChromaDB + e5 multilingual embeddings + BM25 sparse search + LLM re-rank) для сопоставления событий с 88 техниками MITRE ATT&CK. Hybrid search использует веса 0.6/0.4 (vector/BM25) — это решает проблему, когда семантически похожая техника оказывается не той, что нужна
- Внедрил cross-validation слой: YARA (8 правил) и Sigma (9 правил) работают независимо и всегда попадают в отчёт. Raw-анализ от Agent 1 валидируется через RAG/YARA/Sigma — неподтверждённые события уходят в блок ручной проверки (`unconfirmed_events_count`) и не завышают severity (anti-hallucination механизм)
- Настроил CI/CD (Docker Hub + GitVerse), Docker Compose на 5 сервисов (Postgres, FastAPI, Kafka + Zookeeper, Vector, Vue.js frontend)
- Написал 16 тестов для пайплайна: agent1, agent3, RAG eval (ground truth), YARA/Sigma, интеграционные, включая conftest.py с фикстурами

**Метрики (на синтетическом датасете ~850 строк, 38 техник MITRE):** precision 85.7% (30/35), recall 78.9% (30/38), F1 = 0.82. YARA/Sigma не детектировали на синтетике — архитектурно ветка корректна, нужен датасет с реальными атаками.

**Пайплайн в цифрах:** ~3.5 строк/сек (bottleneck: sequential LLM + cloud round-trip, не архитектурный). Для продакшена требуется локальный GPU + batch inference (vLLM/SGLang).
